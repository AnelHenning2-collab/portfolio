Security Awareness Training, Built Exactly Like the Modules KnowBe4 Sells

Two interactive microlearning modules — phishing recognition and HIPAA security awareness — built with the same short, scenario-driven, self-check format used across the security awareness training category.

What this is: Original instructional design work I built independently, not client work for or commissioned by KnowBe4. It's offered here as a leave-behind sample of my own microlearning modules, sized for a quick review.

Why I built this for KnowBe4's marketing team

James Hansel works marketing operations at KnowBe4, a company whose entire product category is security awareness training. Rather than write copy about that category, I built two working modules in it — a phishing hotspot exercise and a HIPAA awareness module — using the same short, interactive, self-check format the category runs on. Both are already live in my instructional design portfolio; this page pulls them together as a single quick-review sheet.

Why This Format, Not a Slide Deck

Security awareness training fails when it's read passively. Both modules force a decision — tap the red flag, answer the scenario — before the learner can move on, which is the same completion logic KnowBe4's own training platform is built around. I built these because I wanted to prove I understand why the format works, not just that I can write copy describing it.
